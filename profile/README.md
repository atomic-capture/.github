# Atomic Capture

Small tools that run from a single file. No install, no server, no account.

Atomic Capture consoles are single-file HTML apps you open in any browser. They work offline, send nothing over the network, and save your work as plain JSON files that you own and keep wherever you want.

## Why

Most admin work is people retyping the same information into different places. Atomic Capture is a pattern for capturing information once, in small structured pieces, so it can be reused, handed off, or passed to AI instead of retyped.

## How to use a console

Download the .html file (or open the live link), open it in your browser, and save your data as JSON. Load it back anytime.
